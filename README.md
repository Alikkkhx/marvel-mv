# 🎬 Marvel Movie Tracker Pro

## 📌 Описание
Профессиональное приложение для отслеживания фильмов MCU с мультиязычной поддержкой, аналитикой и системой рекомендаций.

## ✨ Ключевые возможности
- **Каталог 2008–2027**: Все фильмы 1-6 фаз.
- **Мультиязычность**: Названия и описания на RU и EN.
- **Аналитика**: Персональный дашборд с графиками прогресса.
- **Рекомендации**: Умная система подсказок "Что смотреть дальше".
- **Интерактив**: AJAX-отметки о просмотре, модальные окна, адаптивный дизайн.

## 🚀 Технологии
- Django 5.2 + DRF
- Tailwind CSS (Premium Dark Theme)
- Chart.js
- SQLite

## ⚙️ Установка
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`
3. Выполните миграции: `python manage.py migrate`
4. Загрузите данные: `python manage.py seed_mcu`
5. Запустите сервер: `python manage.py runserver`
