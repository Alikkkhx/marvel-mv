RENDER — ПОШАГОВО (для друзей, бесплатно)

================================================================================



0) Код в GitHub

   Залей папку проекта (marvel-mv) в публичный/приватный репозиторий.



1) База Neon (бесплатный Postgres) — https://console.neon.tech

   - Create project → скопируй Connection string (URI), формат postgresql://...

   - В конце иногда добавляют ?sslmode=require — оставь как в Neon.



2) Аккаунт Render — https://render.com (логин через GitHub).



3) New → Blueprint (или Web Service, см. ниже).



   ВАРИАНТ A — Blueprint (файл render.yaml уже в репо):

   - New → Blueprint → выбери репозиторий и ветку (main/master).

   - Render создаст Web Service. Имя сервиса станет URL: ИМЯ.onrender.com



   Сразу в Environment (переменные) ДОПИШИ (или проверь после создания):



   DATABASE_URL    = (вся строка из Neon)

   ALLOWED_HOSTS   = ИМЯ.onrender.com

   CSRF_TRUSTED_ORIGINS   = https://ИМЯ.onrender.com

   CORS_ALLOWED_ORIGINS  = https://ИМЯ.onrender.com



   SECRET_KEY и DEBUG=False уже заложены в render.yaml (SECRET_KEY сгенерится).



   ВАРИАНТ B — вручную Web Service (без Blueprint):

   - New → Web Service → репозиторий.

   - Build Command:

     pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate && python manage.py seed_mcu

     (сид в build, т.к. на free tier нет Shell. После первой успешной заливки при желании удали "&& ... seed_mcu" из команды.)

   - Start Command:

     gunicorn config.wsgi:application --bind 0.0.0.0:$PORT

   - Добавь все переменные как в render.yaml + Neon DATABASE_URL + три строки

     ALLOWED_HOSTS / CSRF / CORS (как выше, подставь своё ИМя.onrender.com).



4) Apply / Deploy. Дождись “Live” (зелёный). Первый запуск после сна = до ~1 мин.



5) Фильмы в базе (сид)

   - На бесплатном плане Shell на Render нет, поэтому в шаге 3 / render.yaml build уже сделан с

     "&& python manage.py seed_mcu" — при деплое база заполняется сама.

   - Вручную (Neon) с твоего ПК: в корне проекта создай файл neon_database_url.txt (одна строка —

     тот же DATABASE_URL, что в Render), в .gitignore он есть. Потом в PowerShell из папки проекта:

     .\seed-neon.ps1

   - Платный Shell на Render, если появится:  python manage.py seed_mcu



6) Ссылка https://ИМЯ.onrender.com — отдай друзьям. Регистрация/логин — как локально.



--------------------------------------------------------------------------------

Если build падает на migrate — проверь, что DATABASE_URL в Render добавлен

и строка валидная (копипаста из Neon без лишних пробелов).
